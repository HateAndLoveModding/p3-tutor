Where information lives in an agent

PlaceLastsUse it forCost
Context windowOne model call (the program re-sends it each step)Rules, tool descriptions, this request's history and tool resultsTokens, on every call
Saved notes or recordsBetween sessionsSmall, durable facts: training status, preferencesTokens only when loaded
Searchable store (retrieval)Until the documents changeLarge documents: manualsTokens only for returned chunks
Fetched by a toolNever savedChanging facts: the calendarOne tool call

Rules of thumb

  • The model keeps nothing between calls; the program re-sends the whole list.
  • Cost grows with each step: later calls re-read earlier tool results. Trim bulky results.
  • When a long task fills the window: clear used tool results, compact, or hand work to a sub-agent.
  • Save durable facts; fetch changing ones fresh.
  • Retrieval: chunk, index by meaning (embeddings) and keywords (BM25), return the top few. Under about 200,000 tokens, consider skipping it.

Sources: Anthropic Engineering, Contextual Retrieval.
