# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Primary source on context as a finite resource, compaction, structured note-taking, just-in-time retrieval and sub-agents. Use for: anything about what an agent keeps in context and what it saves.
- [Article: "Introducing Contextual Retrieval" (Anthropic)](https://www.anthropic.com/news/contextual-retrieval)
  Explains chunks, embeddings, BM25, the 200,000-token "just include it all" rule of thumb, and retrieval failure rates. Use for: designing how the assistant finds the right page in a manual.
