# Open misconceptions: the model runs tools itself (M4), and it remembers across sessions (M3)

On quiz 0001 (submission s1), Riley understood that an agent is a loop and that a step limit stops a stuck one. They believed the model itself opens systems and runs the tools (M4), so they counted 1 model call instead of 4. They also said the model remembers earlier sessions on its own (M3).
Later lessons should keep separating what the model writes (a request naming a tool and its arguments) from what the program does (runs the tool, returns the result, calls the model again), and should teach memory as something the program saves and supplies.

**Evidence:** quiz 0001, submission s1, items q2, q4 and q6; correct on q1 and q3.
