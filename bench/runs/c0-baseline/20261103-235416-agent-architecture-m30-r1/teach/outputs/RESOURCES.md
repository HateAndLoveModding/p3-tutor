  Primary source on context as a finite attention budget, context rot, compaction, note-taking, just-in-time retrieval and sub-agents. Use for: anything about what an agent keeps in context and how to manage it.
- [Article: "Introducing Contextual Retrieval" (Anthropic)](https://www.anthropic.com/news/contextual-retrieval)
  Explains chunking, embeddings, BM25, why chunks lose context, and the fix, with measured gains; also says a knowledge base under about 200,000 tokens may fit in the prompt. Use for: designing search over the machine manuals.
