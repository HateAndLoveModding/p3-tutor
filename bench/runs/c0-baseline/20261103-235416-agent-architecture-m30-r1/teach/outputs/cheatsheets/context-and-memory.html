Context and memory: one page

From Lesson 1. Source: Anthropic, Effective context engineering for AI agents.

Terms

  • Context: the text sent to the model on one call (system prompt, tool descriptions, transcript).
  • Context window: the limit on that text, in tokens.
  • Context rot: recall of details can get worse as the window fills.
  • Transcript: messages, tool requests and results the program keeps and re-sends.
  • Compaction: summarize a long conversation and continue in a fresh window.
  • Notes: facts saved outside the window and loaded later.
  • Retrieval: search a collection and put only the best chunks in the context.

Which tool for which fact?

NeedUse
Needed on every call of this requestContext
Exact fact that must survive between visitsSaved notes or a lookup tool, loaded into context
Long conversation near the limitCompaction (and clear old tool results)
Long reference documentsRetrieval (chunk, index, search); small sets may fit in the prompt

Cost rule

Input on call n = fixed prefix + everything added so far. Total input = the sum over all calls, so a result left in the transcript is paid for again on every later call.

Retrieval checklist

  • Label each chunk with its machine and section before indexing.
  • Combine meaning search (embeddings) with exact-word search (BM25) for part numbers and codes.
  • Return few, small chunks.
