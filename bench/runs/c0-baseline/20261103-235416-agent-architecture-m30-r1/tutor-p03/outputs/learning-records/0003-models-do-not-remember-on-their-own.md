# A language model does not remember earlier conversations on its own

The learner assumed the model would automatically remember what each student said last week. This was corrected in chat: the model only sees the text sent in the current request, so any memory across sessions has to be saved and re-supplied by the assistant's own code.
Whether the correction landed is still to be confirmed; later lessons on memory should build on it.

**Evidence:** the learner's chat message on 2026-11-03 (misconception stated, then corrected).
**Implications:** the next lesson on context and memory should start from "what does the code save, and what does it put back into the prompt?"
