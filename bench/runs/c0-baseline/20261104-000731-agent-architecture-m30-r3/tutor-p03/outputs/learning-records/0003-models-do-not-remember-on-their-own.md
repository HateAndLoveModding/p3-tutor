# Misconception: language models remember past conversations on their own

Riley assumed the makerspace assistant would automatically remember what each student said last week. This was corrected in chat: a model keeps nothing between calls, and any memory has to be stored by the application and put back into the model's context. Whether the correction landed is not yet confirmed; check it with a retrieval question next session.

**Evidence:** chat message at the start of the context-and-memory topic.
**Implications:** The next lesson on context and memory should start from this point: the context holds only what the app sends, and saving between sessions is a design choice, with a cost, for the team to make.
