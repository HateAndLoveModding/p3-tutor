# Open misconceptions: the model runs tools itself (M4) and remembers on its own (M3)

On quiz 0001 (s1), Riley understood the loop shape, the need for a step limit, and that tool choice comes from descriptions. Riley also said the model "runs the 3 tools itself" (q2, q4) and that it remembers earlier sessions on its own (q6).
Before teaching context and memory, separate what the model outputs (text, including tool requests) from what the program does (runs tools, stores and re-supplies information).

**Evidence:** quiz 0001, submission s1, items q1-q6.
