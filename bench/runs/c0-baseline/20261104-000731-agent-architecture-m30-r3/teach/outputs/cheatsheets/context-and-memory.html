Context and memory in an agent

From lesson 1 (objective O3).

Where does a fact live?

HomeHoldsLastsExample
WindowSystem prompt, tool descriptions, messages, tool resultsOne session; rebuilt each callRules; today's calendar result
NotesSmall, specific facts, saved by a tool or the programAcross sessions"Sam: 3D printer trained"
LibraryLarge reference text, split into chunksPermanent; searched on demandMachine manuals

Key rules

  • The model keeps nothing between calls; the program re-sends the history.
  • Total input tokens = the sum of the window size at every call, not the final size.
  • Tool results usually dominate growth. Clear them once used.
  • A fuller window can be less accurate (context rot). Aim for the smallest set of high-signal tokens.
  • Compaction summarizes one long conversation; notes carry facts to later sessions.
  • Retrieval: chunk the manuals, search (keywords or embeddings), put only the best chunks in the window. Up front, or just in time via a tool.

Terms

  • Token: a small piece of text; the unit of window size and billing.
  • Context window: all the text the model can use for one response.
  • Context rot: accuracy and recall fall as the window grows.
  • Compaction: summarize and restart the window from the summary.
  • Embedding: numbers standing for a text's meaning; similar texts are close.
