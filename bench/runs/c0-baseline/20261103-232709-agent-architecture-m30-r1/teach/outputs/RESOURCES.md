# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Attention budget, context rot, compaction, note-taking, just-in-time retrieval, sub-agents. Use for: anything about what goes in an agent's context.
- [Docs: Context windows (Claude Platform)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  How the window accumulates, what counts toward it, window sizes, compaction and context editing. Use for: concrete limits and mechanics.
- [Article: "Introducing Contextual Retrieval" (Anthropic)](https://www.anthropic.com/engineering/contextual-retrieval)
  Why bare chunks fail in retrieval and one fix, with measured results. Use for: designing manual search.
- [Docs: Memory tool (Claude Platform)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
  File-based memory between sessions. Use for: implementing saved notes.
