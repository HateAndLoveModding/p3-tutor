# Belief that the model remembers across sessions on its own

Riley correctly rejected "automatic memory of every earlier conversation" as what defines an agent (quiz 0001, q1), but the same belief reappeared in their own words in q6: that the model "remembers on its own which tool it picked for questions like that in earlier sessions." Riley knows the idea is wrong when it's offered as an answer choice, but still reaches for it unprompted when explaining tool selection — M3 is not yet gone, just suppressed when the wrong option is spelled out.

**Evidence:** quiz 0001, submission s1, items q1 (correctly rejected as option b) and q6 (restated as an added claim).

**Implications:** This is the right lead-in to context and memory, next in the mission: Riley needs to see that any persistence across sessions is something the assistant's program must deliberately save and re-feed into context, not something the model does by itself.
