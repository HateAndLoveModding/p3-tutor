# Misconceptions to work on: the model runs tools itself (M4) and remembers by itself (M3)

On quiz 0001 (s1), the learner believed the model opens the booking system and runs the tools itself, in one call (q2, q4), and that it remembers earlier sessions on its own (q6).
They do know the loop, the step limit and that tool choice comes from descriptions, so the fix is the split between model and program.

**Evidence:** quiz 0001, submission s1, items q1-q6. Graded correct on q1 and q3, partial on q5 and q6, wrong on q2 and q4.

**Implications:** Before building on context and memory, have the learner label each step of a request as 'model call' or 'program action'. Memory has to be introduced as something the program puts back into the input.
