Context and memory in an agent

From lesson 1.

Terms

TermMeaning
ContextThe tokens the model sees at one call: rules, tool descriptions, conversation so far.
Context windowThe most tokens a model can take in per call.
Context rotRecall gets worse as the context grows.
SessionOne run of the assistant; its context is discarded at the end.
MemoryNotes in storage outside the window, written and read through tools.
RetrievalFetching a few relevant chunks of a large source into context.
CompactionSummarizing a long conversation and starting a new window with the summary.

Rules to remember

  • The model keeps nothing between calls; the program re-sends the context every step.
  • Input cost of a request = the sum of the context size at each call.
  • Clear used tool results; compact only in long tasks.
  • Nothing survives a session unless the program saves it and loads it back.
  • Exact facts: program-owned record plus a lookup tool. Soft details: model-written notes.
  • Retrieve the fewest chunks that reliably hold the answer, with page numbers.
