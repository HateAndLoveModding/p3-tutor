Where does this information belong?

From Lesson 1, Context and memory in an agent (Objective O3).

Ask these in order:
  1. Does the model need it to answer this call? If no, keep it out of context entirely.
  2. Will it still be needed a few steps later in the same task? If yes, it stays in the transcript automatically — the program resends it on every call until the task ends.
  3. Does it need to be true again in a later, separate session? If yes, it must be written outside the conversation and reloaded — nothing crosses sessions on its own.
  4. Is the source large and mostly fixed (a manual)? Use retrieval: search it, pull in only the matching chunk.
  5. Is it one small fact about one person or thing, set once and carried forward (training status, a preference)? Use a note: write it, store it outside context, load it back by key.

Four things, told apart

ThingLives whereCarries forward how
Context windowOne model callDoes not carry forward on its own; it is rebuilt by the program every call.
Within one taskThe growing transcriptAutomatic: the program resends the full history every call, until the task ends.
RetrievalOutside context, in chunksSearched on demand; only the matching chunk(s) enter context.
NotesOutside context, as a saved factWritten once when established; reloaded by key at the start of a later session.

Two mix-ups to catch yourself on

Tempting thoughtWhat's actually true
"A bigger context window means better or more remembered answers."Bigger only means more room. Recall can still degrade as tokens grow (context rot), and a new session starts empty regardless of window size.
"Retrieval and notes are just ways to store the whole thing somewhere."Both exist to keep what lands in context small: retrieval sends one matching chunk, not the whole document; a note is one compact fact, not a saved transcript.
