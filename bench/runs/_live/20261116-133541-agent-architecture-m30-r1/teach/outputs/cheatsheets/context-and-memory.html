Context and memory in an agent

From Lesson 1.

Three kinds of memory

KindLives inLastsMakerspace use
Context (message list)The requestOne runQuestion, tool results so far
NotesStorage you controlAcross sessionsTraining status, unfinished bookings
Retrieval sourceDocuments and searchUntil updatedMachine manuals

Rules

  • Context counts: system prompt, tool definitions, all messages and tool results, and the response.
  • History is re-sent on every call: total input = sum of each call's context.
  • Fuller context recalls worse (context rot): keep the smallest set of useful tokens.
  • Shrink with tool result clearing (light) or compaction (summary).
  • Nothing persists between sessions unless your program saves and reads it.
  • Save small, durable facts; read changing facts live; retrieve documents, do not load them whole.
  • Retrieval: up front, just in time (search then read), or hybrid (small index plus tools).
