# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Primary source on context rot, attention budget, just-in-time retrieval, compaction, note-taking and sub-agents. Use for: what goes in context, how to retrieve, how to keep long runs small.
- [Docs: Context windows (Claude Platform)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  What counts toward the window, how history accumulates, compaction and context editing. Use for: token accounting and cost per request.
- [Docs: Memory tool (Claude Platform)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
  Client-side file memory under /memories and the multi-session pattern. Use for: designing what the assistant saves between sessions.
